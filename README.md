# 24ADI004_TEAM-2
🌍 Global Life Expectancy Paradox
📌 Project Overview

This project analyzes the relationship between life expectancy and major economic, social, and health indicators using the WHO Life Expectancy dataset.

We aim to understand whether wealth truly leads to longer life and how factors like education, adult mortality, and disease prevalence influence life expectancy across countries.

🎯 Objective

Study the impact of GDP, Schooling, Adult Mortality, HIV/AIDS, and other factors on Life Expectancy.

Perform data cleaning and preprocessing.

Conduct Exploratory Data Analysis (EDA).

Identify key statistical patterns and correlations.

Dataset Overview :  

Source: World Health Organization (WHO) - KAGGLE DATASETS . 

Link : https://www.kaggle.com/datasets/kumarajarshi/life-expectancy-who 

Type: Country-wise, yearly panel data 

Key Attributes: Country, Year, Status (Developed/Developing), Life Expectancy, GDP, Schooling, Immunization indicators (Polio, Hepatitis B, Diphtheria), Mortality rates, Population 

Challenges Identified: 

Missing values (especially for developing countries) 

Mixed data types (categorical + numerical) 

Potential outliers in GDP, population, and mortality variables
